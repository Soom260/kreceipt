# 검증 기록 (초안)

> **입력·기대 결과·근거(재현 방법)** 는 미리 채워 두었습니다. **실제 결과와 판단은 직접 해 보고 채워 주세요.**
> 판단 칸에는 `통과` / `실패` / `부분 통과` 중 하나와 짧은 이유를 적습니다.
> 공개 주소: `https://soom260.github.io/kreceipt/` (아래 표에서는 `{주소}` 로 줄여 씀)
> 숫자 규칙(글자 수·금액 등)은 `js/config.js` 의 `LIMITS` 기준입니다.
> 확인한 기기·브라우저: (예: 갤럭시 S○○ 크롬 / 아이폰 ○○ 사파리 / 윈도 크롬) — 직접 적기
> 확인 날짜: (직접 적기)

## 경계

| # | 입력 | 기대 결과 | 실제 결과 | 판단 | 근거 |
|---|---|---|---|---|---|
| 경계-1 | 직접 입력, 금액 `1` | 다음 단계로 넘어감 (최솟값 허용) | | | `{주소}#home` → "직접 입력하기" |
| 경계-2 | 금액 `10000000` (상한) / `10000001` | 1천만 원은 통과 / 1천만 1원은 "금액은 10,000,000원까지 적을 수 있어요." | | | 같은 화면 |
| 경계-3 | 항목 이름 20자 / 21자 | 20자는 통과 / 21자는 "항목 이름은 1–20자로 적어 주세요. 지금 21자입니다." | | | 같은 화면 |
| 경계-4 | 한마디 60자 / 61자 | 60자는 통과 / 61자는 "한마디는 60자까지 쓸 수 있어요. 지금 61자입니다.", 글자 수 표시가 빨갛게 | | | 3단계 |
| 경계-5 | 항목 10개 체크 / 11개 체크 | 10개는 통과 / 11개는 "한 영수증에는 10개까지 넣을 수 있어요. 지금 11개를 골랐어요." | | | 2단계 "+ 항목 추가" 10번 |
| 경계-6 | 항목 10개 × 20자 + 한마디 60자 + 노래로 만든 링크 | 링크가 만들어지고(2,000자 이하), 다른 브라우저에서 열림. (AI 계산: 무작위 한글 20자 × 10개 + 한마디 60자 + 이름 10자 + 긴 곡명일 때 약 1,160자 → 지금 규칙 안에서는 "링크가 너무 길어져요" 안내가 나올 일이 없음. 안전장치로만 둠) | | | 링크 길이 상한 `LIMITS.linkMax` |
| 경계-7 | 이름 10자 / 11자 | 10자 통과 / 11자는 "이름은 10자까지 쓸 수 있어요. 지금 11자입니다." | | | 3단계 |

## 실패

| # | 입력 | 기대 결과 | 실제 결과 | 판단 | 근거 |
|---|---|---|---|---|---|
| 실패-1 | 샘플 캡처로 해보기 (`?sim=error`) | 무슨 일 / 왜 / 할 일 + "다시 시도", "직접 입력하기" 버튼 | | | `{주소}?sim=error#make-1` |
| 실패-2 | 노래 검색 (`?sim=error`) | 노래 영역만 오류 안내 + 다시 시도. 영수증은 노래 없이 만들 수 있음 | | | `{주소}?sim=error#home` → 직접 입력 → 3단계 |
| 실패-3 | 손상된 링크 열기 | "영수증 링크가 손상됐어요" / 왜: 링크 일부가 잘렸거나 바뀌었을 수 있어요 / 할 일: 다시 받아 보세요 + "내 영수증 만들기" | | | `{주소}#r=abc123` |
| 실패-4 | 정상 링크 끝 10글자 정도 지우고 열기 | 실패-3과 같은 안내 | | | 정상-3 링크를 고쳐서 |
| 실패-5 | 노래가 들어간 링크를 `?sim=error` 로 열기 | 영수증은 보이고, 노래 칸에 곡명·가수 글자 + "노래 정보를 불러오지 못했어요" + 다시 시도 | | | 정상-3 링크 앞에 `?sim=error` 를 넣어서 (`…/kreceipt/?sim=error#r=…`) |
| 실패-6 | 보관함 사용 불가 (`?sim=nostorage`) | 보관함: "보관함을 열 수 없어요" 안내 / 받은 영수증 "보관하기": "이 브라우저에서는 보관할 수 없어요. 이미지로 저장…" | | | `{주소}?sim=nostorage#box` |
| 실패-7 | 로딩 상태 (`?sim=slow`) | 3초 동안 "…중" 문장 + 진행 막대 + 회색 자리 | | | `{주소}?sim=slow#make-1` → 샘플 |
| 실패-8 | 인터넷 끊고(비행기 모드) 노래 검색 | 실패-2와 같은 안내 | | | 실제 기기 |
