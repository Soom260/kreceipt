## AI가 점검 중에 찾아서 고친 문제 (참고)
1. 샘플 캡처에서 날짜 줄을 못 읽음 — OCR이 "10월"을 "108"로 읽음 → 요일이 함께 있는 줄은 느슨하게 읽도록 고침 (`js/parse.js`)
2. 가게명 앞에 "0 ", "홍 " 같은 글자가 붙음 — 동그라미 아이콘을 글자로 읽음 → 맨 앞 한 글자 낱말·동그라미 모양 글자를 지움 (단, "CU 연남점"의 CU는 남김)
3. 저장한 이미지에서 한글 줄바꿈이 겹침 — 이미지 안에서는 웹글꼴을 못 써서 글자 폭이 달라짐 → 저장하는 순간만 기기 글꼴로 바꿔 맞춤 (`js/image.js`, `.receipt--export`)
4. "직접 입력하기" 직후 빠르게 입력하면 글자가 다른 칸으로 들어갈 수 있었음 (50ms 뒤 초점 이동 때문) → 화면 전환 때 바로 첫 칸에 초점 주도록 바꿈
5. 360px에서 금액 칸이 좁아 안내 글자가 잘림 → 시간 칸을 줄이고 안내를 "금액"으로
