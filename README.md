## 4. 사용법
<!-- 안내: 채점자가 이것만 보고 처음부터 끝까지 해 볼 수 있게 번호 순서로. 샘플로 해 보는 길을 맨 앞에 -->

📌 참고 메모 (실제 화면 이름 기준)
1. 공개 주소 → **샘플 캡처로 해보기** (자기 결제내역이 없어도 됨. 처음 한 번 인식 데이터 약 8MB를 받느라 몇 초~수십 초 걸림)
2. **확인하고 고르기**: 글자를 고치고 영수증에 넣을 항목 체크 → 다음 (캡처 없이 하려면 홈의 **직접 입력하기**)
3. **한마디와 노래**: 둘 다 선택. 노래는 2자 이상 적으면 검색 → **고르기**
4. **영수증 만들기** → 영수증 확인 (자동으로 보관함에 저장)
5. **링크 보내기** (휴대전화는 공유 시트, PC는 링크 복사) / **이미지로 저장**
6. 받은 링크를 다른 브라우저나 시크릿 창에서 열기 → **보관하기**
7. 위쪽 **보관함** → 전체 / 내 영수증 / 받은 영수증
- 상태 다시 보기 주소: `?sim=slow`(로딩 3초) · `?sim=error`(OCR·노래 실패) · `?sim=empty`(인식·검색 결과 없음) · `?sim=nostorage`(보관함 사용 불가) · `#r=abc123`(손상된 링크) · `?debug=1`(지금 화면 상태 칩). 여러 개는 `?sim=slow,error&debug=1`
- 예: `https://soom260.github.io/kreceipt/?sim=error#make-1`

## 7. 알려진 한계
<!-- 안내: 지금 안 되는 것, 왜 그렇게 정했는지, 다음 단계(9주차 Vercel 이전 후) -->

📌 참고 메모
- 금융앱·마이데이터·오픈뱅킹 실연동 안 함 (허가받은 사업자만 가능) → 캡처 OCR로 대신
- OCR 지원 형식: 한 거래가 "가게명 + 금액(-4,500원)" 줄과 "시간" 줄로 된 목록 화면. 날짜 줄은 "10월 10일 토요일", "2026.10.10", "10.10 (토)" 형태. 입금(+)·환불·취소 줄, 잔액·한도는 버림
- 가게 아이콘을 글자로 잘못 읽는 것을 지우다 보니, 가게명이 "한 글자 + 띄어쓰기"로 시작하면(예: "더 카페") 앞 글자가 빠질 수 있음 → 확인 단계에서 고침
- 노래 검색이 한국(KR) 스토어에서 안 돼 미국(US) 스토어 사용 → 한국 곡 제목이 영어로 나오기도 함. 분당 약 20회 호출 제한
- 이미지 저장 시 웹글꼴 대신 기기 글꼴로 그려짐
- 보관함은 브라우저별 저장 (카톡 인앱 ↔ 크롬 따로, 데이터 삭제 시 사라짐 → 내보내기/가져오기)
- 링크를 가진 사람은 누구나 볼 수 있고 회수 불가 / 링크 미리보기 이미지는 공통 하나
- 새로고침하면 만들던 영수증 내용이 사라짐 (단계 처음으로 돌아감)
- 카카오 "외부 브라우저로 열기" 스킴은 기기·버전에 따라 안 될 수 있음
- 범위 밖: 친구 추가·피드·로그인·기기 간 동기화, 여러 앱 캡처 형식 전부 지원, 확장 API(우리말샘·날씨·절기)
